# Orthogonal

Connect Cursor and Grok Bot to the Orthogonal API marketplace through the Model Context Protocol (MCP).

## What it does

The plugin adds Orthogonal's hosted MCP server at `https://mcp.orthogonal.com`. Your agent can discover and call APIs available through Orthogonal without installing a local server.

## Authentication

The server uses OAuth. After installing the plugin, select **Authenticate** when Cursor or Grok Bot prompts you, then finish signing in to Orthogonal in your browser. The plugin contains no API keys or other secrets.

## Verify the connection

Ask your agent:

> Use Orthogonal to find an API for web search.

If the agent cannot see Orthogonal's tools, confirm the plugin is installed and enabled, then retry authentication.
